# Shorts Subscriber Studio — ClarioHub API

1. Upload `app.py` dan `requirements.txt` ke repositori GitHub yang terhubung ke Streamlit.
2. Buka Streamlit App > Settings > Secrets.
3. Tambahkan `CLARIOHUB_API_KEY = "API_KEY_ASLI_KAMU"`.
4. Restart/reboot aplikasi.
5. Pilih nama model persis seperti yang tersedia di ClarioHub.

Endpoint: `https://api.clariohub.id/v1`

Jika tidak ingin menyimpan key di Secrets, aplikasi juga menyediakan kolom password API key di sidebar untuk sesi saat ini.

Jangan memasukkan API key asli ke file `app.py` atau repositori publik.
